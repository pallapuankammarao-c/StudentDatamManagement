How to Share the Live Dashboard with Anyone (Public Link)
Public Ready

When you run this application, it starts on your machine. You can let anyone click a link and view this live dashboard in two easy ways:

1. On Same Wi-Fi / Local Network

Anyone connected to the same Wi-Fi can open the dashboard using your computer's IP:

http://<your-local-ip>:5000

Run ipconfig in Windows PowerShell to find your IPv4 Address (e.g. 192.168.1.15:5000).

2. Worldwide Public Link (Free)

Generate an instant, secure public HTTPS URL for anyone in the world:

npx localtunnel --port 5000

Or with Cloudflare Tunnel (no install needed):
ssh -R 80:localhost:5000 localhost.run
